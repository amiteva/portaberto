# Front-end Assignment Instructions

## 🤝 Tips

Your users expect a good user experience and an easy to use but good looking app.

This will be a starter for a technical discussion in the interview. You are welcome to use AI to speed up in this test.

## 📚 Guidelines

- Recommended duration: **4h (manual) or less (AI)**
- Deadline: **7 days from reception**

## Exercice

You must create a small front-end application consuming the public API: **FakerAPI**

The design and architecture are intentionally left open to highlight your creativity and technical decisions.

## Technical constraints

The project must be built with one of the following frameworks:

- Vue.js

You are free to choose:

- the state management solution
- the UI library
- routing
- the styling system
- the overall architecture
- your preferred LLM

---

## Objective

Create an application that lets users explore and manipulate data coming from FakerAPI.

You are free to choose the theme.

### Examples

- user catalog
- book library
- product list
- dashboard
- task manager
- mini CRM
- etc...

---

## Minimum expected features

The application must include:

### 1. API consumption

Use at least:

- one FakerAPI endpoint
- real HTTP calls
- handling of loading and error states

### 2. Data display

Implement:

- a list of items
- a detail view OR a meaningful user interaction

### 3. User interactions

Include several features among:

- search
- filters / sorting
- pagination
- favorites
- form
- local editing / deletion
- navigation
- responsive design

---

- unit tests
